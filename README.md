# giencoder-12s-skills

源启 giencoder 平台（源启智能软件工厂 / 4P12S 交付流程）的 12 个 Skill 集合，对应交付流水线的 12 个阶段。

## Skill 列表

| Skill | 阶段 |
|-------|------|
| 4p12s-requirements | 需求梳理 |
| 4p12s-prd | PRD 编写 |
| 4p12s-user-stories | 用户故事 |
| 4p12s-technical-design | 技术设计 |
| 4p12s-implementation-tasks | 实现任务拆解 |
| 4p12s-implementation-execution | 实现执行 |
| 4p12s-integration-test | 集成测试 |
| 4p12s-e2e-test | 端到端测试 |
| 4p12s-verification-plan | 验证计划 |
| 4p12s-verification-result | 验证结果 |
| 4p12s-deployment-execution | 部署执行 |
| 4p12s-git-push | Git 推送 |
| 4p12s-delivery-orchestrator | 交付编排（总控） |

每个目录包含 `SKILL.md`（技能说明）与 `manifest.json`（清单）。

## 来源

导出自源启 giencoder 平台技能空间（ws=23566）。
